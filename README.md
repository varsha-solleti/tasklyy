# Taskly 📝

A simple and interactive to-do list web application built using HTML, CSS, and JavaScript.

## ✨ Features

- ➕ Add new tasks
- ⌨️ Add tasks using the Enter key
- ✅ Mark tasks as completed
- 📝 Cross out completed tasks
- 🗑️ Delete tasks
- 📊 Track task completion with a progress bar
- 🔢 Display completed and remaining tasks
- 💾 Save tasks using browser localStorage
- 🎉 Show an empty-state message when there are no tasks

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## 🚀 How It Works

1. Enter a task in the input box.
2. Click **Add Task** or press **Enter**.
3. Use the checkbox to mark a task as completed.
4. Delete tasks using the delete button.
5. The progress bar automatically updates as tasks are completed.
6. Tasks are saved in the browser, so they remain after refreshing the page.
